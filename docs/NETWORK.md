# Сеть трансляции

## Основные порты

- TCP 1935 — публикация RTMP с камер;
- TCP 1985 — API SRS;
- TCP 8080 — HTTP-FLV и HLS;
- TCP 4455 — OBS WebSocket на ноутбуке.

## Беспроводной повторитель

MERCUSYS MR30G можно использовать как беспроводной повторитель для Cudy TR1200. Размещать повторитель следует не в мёртвой зоне, а там, где он сам получает устойчивый сигнал основного роутера.

Практические ориентиры:

- −50…−60 dBm — хорошее место;
- −61…−67 dBm — пограничное;
- ниже −68 dBm — лучше передвинуть ближе к Cudy.

Android-приложение различает физические точки по BSSID даже при одинаковом SSID.
